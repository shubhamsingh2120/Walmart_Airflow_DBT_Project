# Walmart Airflow DBT Data Engineering Project

An end-to-end data engineering project that uses Apache Airflow and dbt to build an automated data transformation pipeline for Walmart sales data.

## Technologies Used

- Apache Airflow
- dbt
- SQL
- PostgreSQL
- Docker
- Python

## Project Overview

This project demonstrates an automated ETL/ELT workflow where Walmart dataset files are processed and transformed using Airflow and dbt.

Airflow is used to orchestrate the data pipeline, while dbt is used for SQL-based data transformation and data modeling.

## Project Workflow

1. Load Walmart source data
2. Schedule and orchestrate tasks using Apache Airflow
3. Transform data using dbt
4. Create analytical data models
5. Store transformed data in PostgreSQL
6. Generate clean datasets for analysis and reporting

## Project Structure

- `airflow_dbt_project/` - Airflow and dbt project files
- `walmart_dataset/` - Walmart dataset
- `dags/` - Airflow DAGs
- `config/` - Airflow configuration
- `Dockerfile` - Docker configuration
- `docker-compose.yaml` - Container configuration
